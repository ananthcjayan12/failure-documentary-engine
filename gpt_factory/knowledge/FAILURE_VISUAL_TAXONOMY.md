# Failure Documentary Visual Taxonomy

## Hero reconstruction

A physical event or key environment: aircraft departure, controlled bank, vessel in rough sea, machinery under load, infrastructure before failure.

## Atmosphere

Reusable environmental plate: clouds, runway reflections, empty ocean, control-room ambience, underwater particles, rain, fog, empty terminal.

## Investigation

Evidence and analysis environment: radar room, radio controls, documents, debris examination, sonar operations, satellite, technical panel.

## Story-specific

A unique clue, location, object, or reconstruction needed by only one investigation.

## Selection rule

Prefer a reusable hero, atmosphere, or investigation asset when it can truthfully support multiple shot divisions. Use a story-specific asset only when reuse would weaken factual clarity.
